# To-Do Checklist

A small dark-themed to-do app for Windows, written in Python with Tkinter (no dependencies).

- Lists grouped into colored categories, with drag-and-drop reordering
- Notes on tasks, a Completed view, and Ctrl+Z to undo a check-off
- Data is saved to `todo.json` next to the script

## Run

```
pythonw todo.pyw
```

Run `Make Shortcut.bat` to create a `To-Do.lnk` shortcut with the app icon (it expects the
Python install manager's `pythonw.exe` at `%LOCALAPPDATA%\Python\bin`).
